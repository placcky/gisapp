🌲 Salzburg Tree Cover Change Detection

Interactive analysis of forest cover changes (2018–2024) using Sentinel-2 data

📊 Project Overview

This WebGIS application analyzes tree cover changes across Salzburg's districts between 2018 and 2024 using Sentinel-2 satellite imagery.

Click on any region to view detailed statistics and trends.
